Dein Salon

Alle Schritte für die Benutzung der App.

1. git clone https://github.com/PatrickMvG/Friseur-Salon.git

2. Importiere die salon_db.sql datei in deine Mysql-Datenbank

3. benenne die .env_example in .env um

4. aktualisiere die daten in der .env datei mit denen mysql daten.

5. Öffne das Terminal im Projektordner und installiere alle benötigten Pakete mit:
   `npm install`

6. Starte den Backend-Server im Terminal mit:
   `npm run dev`

7. Clone nun dein Frontend und befolge die Anweisungen im Frontend
